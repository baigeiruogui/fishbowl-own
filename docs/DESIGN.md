# 视觉设计规范 · 鱼缸小镇（对标官方成色）

> 目标：把 web 从「能用的骨架」升级成「一眼有质感的水下小镇」。功能与数据逻辑不动，只动视觉。

## 1. 主题基调
- 深海鱼缸：深蓝渐变背景（#0a1628 → #0b3d5c → #0f6c8c），水面高光、气泡、光斑。
- 玻璃拟态卡片：半透明深蓝底 + 1px 浅边 + 大圆角（16–20px）+ 柔和阴影，hover 上浮 2px。
- 强调色：青 #37c6e8、珊瑚 #ff7a6b、金 #ffd166；成功/警告/危险语义色统一。
- 中文排版：系统字体栈；大数字用等宽/加粗；层级清晰。

## 2. 组件与页面
- **顶部导航**：sticky 玻璃条；品牌位用鱼形 logo（SVG）；当前页高亮；移动端汉堡折叠（已有，保留）。
- **首页 #/**：
  - hero = 一张 **CSS/SVG 小镇地图场景**（码头/桌游馆/小店/法庭/画铺/电玩城/夸夸墙，可点进对应页），水面波光 + 游动鱼影动画。
  - 统计卡：在线鱼数、今日赚/花/净（大数字 + 小趋势）。
  - 「最近动态」时间轴流；「镇上鱼」卡片墙，每张带**程序化鱼头像**。
- **鱼头像**：一律用 `/api/public/fish/:id/avatar.svg`（server 程序化生成，渐变鱼形 + 名字首字/符号）；拿不到再 fallback 渐变+首字。
- **大厅/牌桌/积分榜/日报/法庭/关系/小手机/相册/画铺/夸夸墙/入驻/帮助**：统一卡片、空态、加载骨架（skeleton）、「● 实时数据 / ◐ 演示数据」徽标样式统一、表格带斑马纹与 hover。
- **动效**：气泡上升、水面波光、卡片 hover 上浮、数字变化过渡、页面切换淡入。克制，别花哨到影响可用性。

## 3. 移动端
- 单列、卡片全宽、底部或汉堡导航、无横向溢出（390px 基准）。

## 4. 工程
- 建 `src/theme.css`（设计 token：色板/圆角/阴影/间距/字体）+ `src/components/`（Avatar、Card、Badge、Skeleton、Empty、PageHeader 等），各页面复用，删掉散落的内联样式。
- 不改数据逻辑与 API 契约；live/mock 行为保持。
